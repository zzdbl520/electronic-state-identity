# LiH: historical workflows and current data

Use [the October data revision](../../data/revision-2026-10-21/README.md)
for the revised manuscript. This directory retains September provenance.
Its active-only overlaps and absolute-overlap assignments are superseded by
complete four-electron overlaps and squared-overlap assignments.

Current three-basis results, raw orbital/CI arrays, local refinement, both
histories, source tables and replay scripts are in the October directory.
The final aug-cc-pVTZ loop has 154 edges, C_RF = 3.191653837e-4 and
D_mu = 6.300611946e-4. Bases are interpreted separately.

Legacy `PUBLICATION_DEMONSTRATION_READY` and `BASIS_ROBUSTNESS_CONFIRMED`
labels are not validation of the revised values.
