# BeH2: orbital-constraint sensitivity

Current [tables](../../data/revision-2026-10-21/records/BeH2/) and
[model comparison](../../data/revision-2026-10-21/records/beh2_model_comparison/)
support constraint sensitivity of the energy separation. Failed SA3/SA4 fidelity
prevents loop nonclosure from establishing a physical branch transition.

The old nonclosure ratio, refinement-exponent interpretation and unsupported
precise 12-start statistics are withdrawn. The historical `REVIEW_REQUIRED`
status is preserved. Cross-model restarts are unavailable; the remaining energy
comparison is supported at summary level. See [availability](../../docs/DATA_AVAILABILITY.md).
