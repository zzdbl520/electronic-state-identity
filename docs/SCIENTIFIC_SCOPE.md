# Scientific scope

Polar factors of many-electron overlap matrices define edge transports; singular
values test retained-subspace fidelity. Individual-root assignment margins apply
when individual-root correspondence is part of the comparison. Passing checks
supports interpretation within the chosen model, not active-space completeness.
The three LiH bases are interpreted separately.

- LiH supports resolved transport/operator differences despite identical assignments.
- BeH2 supports orbital-constraint sensitivity; failed SA3/SA4 fidelity prevents
  physical branch-transition claims based on old nonclosure/refinement metrics.
- C5H5+ supports an externally isolated rank-2 pair; initialization sensitivity
  limits precision of the small Wilson phase.
- H3/O3 historical diagnostics include failed tests and are not all positive evidence.

A nonzero route difference alone is not a topological invariant. A rank-2 Wilson
spectrum does not assign a scalar Berry phase to a member, count enclosed conical
intersections, or establish absolute-ground-state identity.

Historical decision labels remain records of their original checks. Current
interpretations are given by the October evidence map and data-availability statement.
