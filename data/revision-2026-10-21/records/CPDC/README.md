# Reference records

These are the final rank-2 projector and opposed-history records used by the
cross-system audit. Machine-specific paths were replaced with
`${CPDC_ARCHIVE_ROOT}`; numerical fields were not changed.

`SHA256SUMS.original-release` is retained as provenance for the unsanitized
return bundle. It is not expected to validate the sanitized copies in this
directory. The repository-level `SHA256SUMS` validates the released files.
